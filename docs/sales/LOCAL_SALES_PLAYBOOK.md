# DailyDo - Playbook Vente Locale

Objectif: vendre DailyDo a des restaurants proches (demo terrain), pas en national pour l'instant.

## 1) Positionnement simple

Phrase d'accroche:
"DailyDo remplace les listes papier et les relances WhatsApp: vous savez en direct ce qui est fait, ce qui reste, et par qui."

## 2) Offre de depart (facile a vendre)

- Starter (1 restaurant): 49 EUR / mois
- Mise en place: offerte (ou 99 EUR une fois)
- Essai: 14 jours

## 3) Script WhatsApp (prospection)

Bonjour [Prenom], j'ai un outil simple pour le suivi des taches en restaurant.
En 10 min, je vous montre comment voir ce qui est fait / pas fait en direct,
avec planning quotidien et code equipe pour les employes.
On peut faire une demo cette semaine ?

## 4) Demo 10 minutes (ordre recommande)

1. Connexion gerant
2. Taches du jour ajoutees automatiquement
3. Statut tache: A faire -> En cours -> Terminee
4. Calendrier: revoir un jour passe et voir fait / non fait
5. Equipe: code a 8 caracteres pour inviter les employes

## 5) Onboarding client (30 min)

- Configurer le planning du lundi au dimanche
- Ajouter 2 checklists (ouverture / fermeture)
- Donner le code equipe au manager
- Test en live avec 1 employe

## 6) Cibles prioritaires locales

- Franchises 2 a 10 sites
- Restaurants avec 6+ employes
- Gerants presents sur le terrain

## 7) KPI a suivre (chaque semaine)

- Nombre de demos realisees
- Taux conversion demo -> essai
- Taux conversion essai -> payant
- Nombre de restaurants actifs
